# Homepage globe

`world.json` contains 2,990 land dots, 5,143 coastline vertices, and exactly 1,000 deterministic **preset display locations**, clustered around cities and checked against the land polygons. The red points do not come from user analytics. Institution markers in `global-users.js` are approximate campus locations for geographic reference; they do not establish users, endorsements, or partnerships.

Land geometry: [Natural Earth 1:110m land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson), downloaded 2026-10-21. Natural Earth data is [public domain](https://www.naturalearthdata.com/about/terms-of-use/). Only land and coastlines are rendered, with no political boundaries. All geometry is served locally; no third-party map service is contacted by the browser.

The data is embedded as the final argument to the IIFE in `global-users.js`, avoiding a separate fetch and allowing direct `file://` previews. `world.json` is retained as the editable source; update the embedded data when changing it. The globe initializes as the section approaches the viewport. The displayed count is “500+”; the 1,000 underlying display points remain unchanged. The Canvas renderer supports drag, arrow keys, Space to pause, Home to reset, and landmark selection. Zoom ranges from 1× to 4× using the +/− controls or keys; double-click centers and enlarges the selected region. Scrolling zooms only while the canvas has focus, leaving ordinary page scrolling and browser Ctrl/Command zoom available. Zooming pauses rotation; reset restores the complete globe. Animation stops outside the viewport and in background tabs; reduced-motion users get a static globe with manual navigation. On touch devices, horizontal drags rotate while vertical gestures remain available for page scrolling.

All 12 institution buttons include local logos, documented in [logos/README.md](logos/README.md). English names are written in full, including University College London; its Chinese name is 伦敦大学学院. Language changes update the text span without replacing the logo.

Before using this as a real user distribution, replace `users` with anonymized, verified geographic data, update the point-count validation and displayed count, and update the visible data description in both languages. Verify institution affiliations separately before describing institutions as users.
