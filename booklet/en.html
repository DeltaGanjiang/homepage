02

PREPARE YOUR DATA

Files & measurement conditions

#

Prepare the inputs for your task and record the actual measurement conditions before configuring the analysis.

FunctionRequired inputs
Phase identificationOne observed pattern; elements and formula hints are optional.
Identification + refinementOne observed pattern; refinement settings are confirmed later.
Known-phase refinementOne observed pattern and a CIF for every phase to refine.
PDF card calculationOne observed pattern and at least one CIF.
XRD simulationOne or more CIF / MCIF files; no observed pattern is needed.
Crystal viewerOne CIF.

Pattern formats

CSVDATRAWTXTXRDMLXY

Submit one observed pattern per task. If an instrument-specific file cannot be parsed, export a two-column CSV or XY file from the instrument software. Renaming the extension does not convert the file.

Two-column text typically contains 2θ in degrees and intensity, with one sample per row. Keep angle and intensity aligned. State whether the file contains a header and whether background subtraction, smoothing or normalization has been applied.

Measurement conditions

Record the sample ID, radiation source or wavelength, horizontal-axis units, scan range and instrument parameter file, if available. Software defaults are not evidence of the measurement conditions.

i
Check the radiation before submitting

The identification and refinement test interfaces described in this edition are fixed to Cu Kα. Do not submit non-Cu data as Cu data by renaming it.

03

START YOUR FIRST TASK

Create a task & confirm parameters

#
  1. Select New task, then choose the required function on the left.
  2. Use + in the task input box to attach the specific files. Check their names; do not upload a whole test-data archive as one pattern.
  3. Enter the analysis goal, sample ID and known conditions in the same box. You can extend the prefilled request. The model selector does not set the phase-search model or radiation.
  4. Send the request. When the confirmation form appears, check the task type, single/multiphase mode, search channels, elements and formula fields.
  5. The final values in the confirmation form govern the calculation. Submit the form after editing it; closing or cancelling it does not start computation.
  6. Check execution messages. If the task is still awaiting plan confirmation, submit the form instead of uploading the same files again.
i
The request and the form

The request describes your intent; the form stores the final settings. Even if the request says “multiphase”, check the mode in the form. Naming two search channels does not prove both ran successfully; check the execution record.

Continue the original task when adding information for the same sample. Create a new task for another sample or a different set of settings, and include the sample ID and conditions in its name to keep outputs distinct.

04

IDENTIFY A PHASE

Single-phase identification

#

Search for candidate crystalline phases from one observed pattern without structural refinement. Unknown-phase identification does not require a CIF. Leave the formula field empty for tests without formula hints.

OptionPurpose
Single phaseSearch under a single-phase assumption; do not remove unexplained observed peaks on that basis.
XMatcherPattern-based candidate matching; available without element constraints.
XQueryer-LWSearch using supplied elements; valid element constraints are required.
Both channelsSelect both models in the single-phase form and check their actual execution status.
Unknown phase countTry single-phase identification first; move to the multiphase workflow if the result is inadequate.
EXAMPLE REQUEST
Identify a single phase in the attached pattern without refinement.
Known elements: Ca Fe Si O
No formula hints. Use XMatcher and XQueryer-LW in the single-phase configuration.
Radiation: [actual conditions]. Preprocessing: [actual treatment or none].

Check the result

Check channel success before reviewing candidate rankings and validation. Top 1 means the highest-ranked candidate, not an automatically confirmed phase. Without a candidate list, there is no Top 1 to select.

05

RESOLVE A MIXTURE

Multiphase identification

#

Multiphase means multiple crystalline phases in one sample pattern, not multiple uploaded patterns. Select Phase identification, attach one mixed pattern and choose multiphase mode in the form. Use unknown phase count when the count is not established.

XMatcher-AutoMix+XDecomposer

The multiphase form offers these two channels. Keep both default channels or select one for a controlled test. Candidates are pooled for validation. Single-phase XQueryer-LW and XMatcher selections do not replace the multiphase settings.

Enter elements separately from formulas

FieldHow to enter it
ElementsEnter unique known symbols, e.g. Ca Al Si O Ni S. Do not guess unknown elements; identify a partial list as incomplete.
Formula hintsLeave empty if unavailable. For known phases, enter one formula per phase, separated by ASCII commas, semicolons or newlines.
CIFFor element-constrained identification without structure hints, upload only the pattern and retain CIFs as reference answers. Attach them for known-phase refinement.
EXAMPLE REQUEST
Identify multiple phases in the attached pattern without refinement or formula hints.
Known elements: Ca Al Si O Ni S
Use XMatcher-AutoMix and XDecomposer in the multiphase configuration.
Radiation: [actual conditions]. Phase count: [unknown or established count].
i

Before submitting, check: one pattern, multiphase mode, correct elements and an empty formula field. “Not reviewed” means validation is pending or missing; it does not mean the candidates have been rejected.

06

FROM CANDIDATES TO FIT

Identification + refinement

#

Identify phases first, then test how candidate structures fit the observed pattern. Supply one pattern and measurement conditions; known elements support the identification stage. Check identification and refinement results separately.

  1. Select Identification + refinement, attach the pattern and specify single phase, multiphase or unknown phase count.
  2. Submit the initial identification form after checking elements, formula hints and search channels.
  3. Review the candidates and their evidence. When the refinement form appears, check the candidate phases or structure files to be used.
  4. Select an available refinement engine and specify the instrument file, if any, fitting range, parameter constraints and cycles. Do not release all atomic parameters merely to improve the fit.
  5. Confirm refinement and keep the task session. If communication is interrupted, check the original task before starting the same calculation again.
  6. Review calculated and observed curves, differences, fit metrics, structure files and validation status, then download the task files.
EXAMPLE REQUEST
Identify phases in the attachment, then refine evidence-supported candidates.
Sample: [ID]. Elements: [known elements or unknown]. Radiation: [actual conditions].
Prioritize scale, background and unit-cell parameters; keep atomic occupancies fixed.
Provide the whole-pattern fit, difference curve, fit metrics and final validation status.
07

REFINE A KNOWN STRUCTURE

Known-phase refinement

#

For samples with existing structure models, skip phase search and refine the supplied CIFs directly. Attach one CIF for a single phase or one per phase for a mixture, together with one complete observed pattern.

  1. Select Known-phase refinement and use + to attach the pattern and all CIFs.
  2. Check the formula, cell and atomic information in every CIF. Avoid duplicate structures and omitted phases.
  3. Confirm the phase mode, structure list, engine and instrument configuration. Use the corresponding IRF file when supplying a FullProf instrument file.
ParameterPurpose & checks
Scale factorsControl phase intensities; they are not directly equal to mass fractions.
Background & profileFit the baseline and peak profiles; do not use background to hide a missing phase.
Zero shift & unit cellAffect peak positions; consider parameter correlations.
Coordinates & occupanciesAffect structure factors; adjust only when supported by data and chemistry.
i

When reporting phase amounts, check the definition, included phases and normalization method. Display scales, candidate scores and refined mass fractions are different quantities.

08

COMPARE REFLECTIONS

PDF card calculation

#

Supply one observed pattern and one or more known CIF structures to calculate theoretical reflections and compare them with observed peaks. This function does not perform unknown-phase identification or Rietveld refinement.

  1. Select PDF card calculation and attach the pattern and all phase CIFs.
  2. Check filenames, wavelength and peak detection/matching parameters in the form.
  3. Submit and review the theoretical reflection table and observed peak table separately, including assignments and unmatched peaks.
  4. Retain phase names and sources when changing visibility, colours or annotations. After editing assignments, export the current version using the report controls.
ParameterInitial valueMeaning
Wavelength1.5406 ÅRadiation for theoretical positions; match the experiment.
Matching tolerance0.20° 2θAllowed observed-to-theoretical position difference.
Intensity threshold10%Relative intensity threshold for observed peaks.
Minimum distance0.08° 2θMinimum separation between detected peaks.
Prominence0%Required prominence above the surrounding baseline.

Initial values are software defaults and must be checked for the dataset. Download theory.csv, peaks.csv, observed.csv, parameters.json or the result bundle. Initial files contain automatic assignments; later manual edits require a new export.

i

A missing match does not by itself prove a phase is absent. CIF-derived reflections do not establish a commercial database card number.

09

FROM STRUCTURE TO PATTERN

XRD simulation

#

Calculate theoretical powder diffraction from CIF or MCIF files without an observed pattern. Upload one or more structures to compare component patterns and their total.

  1. Select XRD simulation and attach the structures; separate files represent separate phases.
  2. Check wavelength, 2θ range, sampling step, peak shape, width and mixing parameter in the form.
  3. Submit and inspect parsing status for every file. If some files fail, only the successful phases are completed.
  4. Adjust visibility, colour, relative display scale and width in the panel. Choose total, overlay or stacked views and inspect the HKL peak table.
  5. Use the panel CSV or SVG export for the current view. Changing wavelength, range or sampling step requires a newly confirmed calculation.
SettingInitial valuePurpose
Wavelength1.5406 ÅCu Kα₁ theoretical calculation
2θ range10–90°Simulation interval
Step0.02°Angular interval for sampled curves
Shapepseudo-VoigtPeak profile function
FWHM0.18°Initial peak broadening
Lorentzian fraction η0.5Profile mixing parameter

Initial downloads include peaks.csv, pattern.csv, parameters.json and a ZIP, using the confirmed settings.

i

Relative display scale is not mass fraction. Simulation does not replace experimental identification or quantitative refinement.

10

LOOK INSIDE THE STRUCTURE

Crystal viewer

#
  1. Select Crystal viewer on the left to open the structure viewer.
  2. Choose one .cif file using the file picker, or drag it into the drop zone if one is provided.
  3. Wait for parsing and verify the current filename and structure information. Load the correct CIF when switching samples so the previous model is not mistaken for the current one.
  4. Use the view controls to inspect atomic arrangements. Return to XRD simulation when you need a diffraction pattern.

Read elements from a CIF

Open the CIF in a text editor and search for _chemical_formula_structural, _chemical_formula_sum or _atom_site_type_symbol. Element symbols identify species; numbers give stoichiometry. An expanded cell formula may have larger numbers than the simplest formula but contains the same element types.

Example formulaElements
Ca₃Al₂(SiO₄)₃Ca Al Si O
NiSNi S
Union of the two phasesCa Al Si O Ni S

If parsing fails

Confirm the file is extracted and is actually a CIF, and check that cell parameters and atomic sites are complete. Renaming a CSV pattern or an image does not make it a structure file.

i

A displayable structure only shows that the model can be parsed. It does not prove the phase has been identified in the experimental sample.

13

RESULT INTERPRETATION

Reading results & assigning conclusions

#

View PDF page 13

The software organizes evidence. Do not accept a phase from a single score, coverage value or low residual alone. Data conditions, peak positions, intensity trends, chemistry and review status must agree.

  1. Verify inputs. Confirm wavelength, 2θ range, background, elemental constraints and sample metadata.
  2. Review candidates. Read the phase name, formula, space group and database ID before the ranking score.
  3. Inspect the pattern. Check principal peak positions and investigate unexplained peaks or systematic intensity errors.
  4. Read validation. Inspect Inspector, the peak-position check and coverage. “Passed” still requires manual verification.
  5. Audit refinement. Compare observed and calculated curves, the difference curve, fit indices and parameter plausibility.
  6. Report the result. State only conclusions supported by consistent evidence. Retain inputs, CIFs, the task ID and exports.
i
Reportable conclusions

Distinguish a candidate, a software-reviewed result and a manually confirmed identification or refinement.

i
Current preview: candidate 3

Candidate 3 has a review score of 8.95 and did not pass review. The first three combinations are not Inspector-trusted. They may be compared but must not be reported as final material conclusions.

  • C2Li4O6 is a doubled-formula representation of Li2CO3; ClNa represents NaCl. Candidate 3 matches the known two-phase composition.
  • Its score is 55.71 and explained intensity is 51.4%, but validation failed. Report it as a candidate only.
  • The third phases in combinations 1, 2 and 4 may reflect over-decomposition. Require diagnostic peaks and a chemically credible sample origin before acceptance.
i
Metric boundaries

Relative diffraction contribution is not weight fraction. Explained intensity measures peak coverage, not purity. Scores rank combinations within this run and are not probabilities or confidence values.

RESULT INTERPRETATION

XRD simulation & PDF card interpretation

#

View PDF page 16

SettingValue in this example
PhasesLi2CO3.cif and NaCl.cif
Radiation / rangeλ = 1.5406 Å; 10–90° 2θ
ProfilePseudo-Voigt; FWHM 0.18°; η = 0.50
PDF tolerance±0.2°
  • Intensity factors change display contribution; global or independent FWHM controls broadening. Neither value is a phase fraction.
  • Simulation checks peak positions, HKL indices and overlap; it does not replace identification from experimental data.
  • Blue P1 markers represent Li2CO3 and dark-red P2 markers represent NaCl. Position matches support phase assignment, but a normalized display cannot be converted directly into phase content.

#

RESULT INTERPRETATION

GSAS-II refinement & result acceptance

#

View PDF page 18

Sharp residuals remain at several intense peaks. Review the model, profile, background and preferred orientation.

Phase / parameterBeforeAfterInterpretation
Phase 1: V237.053556 Å³237.027549 Å³Different space-group setting; delta withheld
Phase 2: a = b = c5.620000 Å5.620648 Å+0.0115%
Phase 2: V177.504328 Å³177.565760 Å³+0.0346%

Acceptance checklist

  • Confirm matching space group, cell setting and CIF identity. A dash does not mean zero change.
  • Principal peak positions and intensity trends agree; the difference curve has no structured or intense residuals.
  • Compare Rwp, Rp and χ² under comparable data quality and the same strategy. Low Rwp alone is insufficient.
  • Cell, profile, background, preferred-orientation and atomic parameters remain physically plausible.
  • For quantitative analysis, phase fractions sum to approximately 100%. Report uncertainty, constraints and unmodelled phases.

ACCOUNT & MODEL SETUP

Software overview & standard workflow

#

View PDF page 19

GanJiang organizes XRD processing, phase search, candidate review, PDF-card matching, theoretical-pattern simulation and structure refinement. Outputs support an evidence chain; final conclusions still require sample context and manual verification.

Core moduleContent
Phase identificationSingle-phase or multiphase candidates, elemental or formula constraints, ranking and Inspector review.
Patterns and cardsObserved patterns, theoretical peaks, HKL labels, PDF-card matching and unexplained peaks.
Structure and refinementCIF viewing, XRD simulation, PyXplore / GSAS-II refinement and cell comparison.
Tasks and exportsTask status, record retrieval and CSV / SVG / PNG / CIF exports.

Standard workflow

  1. Prepare XRD / CIF.
  2. Create a task.
  3. Review candidates.
  4. Run validation.
  5. Refine if needed.
  6. Export and archive.

ACCOUNT & MODEL SETUP

Account top-up & quota check

#

View PDF page 20

Confirm the signed-in account and determine the amount, payment method and invoice requirement. Balance, plans, pricing and payment channels follow the current in-app display.

  1. Open the account page. Use the account or avatar entry to open the account, quota or top-up page.
  2. Select an item. Choose an available plan or amount. Verify currency, validity, scope and refund terms.

i

Keep a masked order number, time, amount and status capture, then contact support. Do not pay again merely to test.

TROUBLESHOOTING

LLM not configured or temporarily unavailable

#

View PDF page 26

i
Messages to identify

“LLM is not configured” or “LLM configuration is temporarily unavailable.”

Method 1: use a system model provided with the account

  1. If Go to Sign In is shown, sign in first. If already signed in, confirm network access.

TROUBLESHOOTING

Environment dependencies at first launch

#

View PDF page 27

This is the normal environment-preparation process. The application checks required dependencies and starts installation when any are missing.

  1. Review which dependency is being processed and wait for completion. Follow the prompts if a system terminal opens.
  2. Enter the computer administrator password only when the system requests authorization, not the GanJiang password. Terminal input may remain invisible; press Enter after typing.
  3. Return to Settings → Environment Variables and select Detect Again.
  4. Confirm that required dependencies are detected. Install optional dependencies when their functions are needed.

If installation fails

  • Expand View Detailed Output on the preparation page and record the failure message.
  • Open Settings → Environment Variables and retry Install for supported missing dependencies.
  • If no terminal is found, run the command shown by the application in the system terminal, then select Detect Again.
i

Skip and Continue or Continue Using only opens the application. It does not install missing dependencies, and affected functions may remain unavailable.
