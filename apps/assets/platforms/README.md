# Desktop platform marks

- `apple.svg`: the unchanged Apple mark path from the global navigation on
  https://www.apple.com/ (retrieved 2026-10-21). The viewBox trims the navigation
  bar's vertical whitespace, and the mark is white for the dark background.
- `windows.svg`: the standard four-square Windows mark from
  https://commons.wikimedia.org/wiki/File:Windows_logo_-_2021.svg
  (original https://upload.wikimedia.org/wikipedia/commons/8/87/Windows_logo_-_2021.svg).
  The geometry and blue color are preserved. Commons identifies the simple
  geometric design as public domain; the mark remains a Microsoft trademark.

These local vectors identify supported operating systems. Both platform links
lead to the page's download-center section; they do not link to installers.
