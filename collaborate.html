01 / OPEN SOURCE

开源共建

带上代码仓库、软件版本、开源许可证与评测结果。我们一起评估工具能力、复现表现和接入方式，在遵循原有许可证的基础上推进集成与联合开发。

  • 尊重原作者署名与开源许可证
  • 共同完善接口、文档与研究场景
  • 让工具在真实分析流程中持续改进
02 / CLOSED SOURCE

闭源合作

无需公开源代码，也可以提交评测结果与接口说明。通过评估后，我们可讨论商业采购、软件授权或联合研发，并通过 API、可执行程序或私有服务接入。

  • 按约定在干将中闭源调用
  • 不向外部披露或分发源代码及未公开技术资料
  • 采购、授权范围与保密安排由双方书面确认
03 / ACADEMIC RESEARCH

学术项目合作

如果你希望使用干将开展学术研究、功能测试或与其他方法进行对比分析，欢迎提交研究 proposal。我们将审核项目，通过后开放限额免费的 GanJiang API，支持你的分析工作。

  • 说明研究目标、数据与实验或对比方案
  • 提交预计调用量与项目周期，供额度评估
  • 审核通过后，在获批额度内免费调用 API
提交研究 Proposal

BUILD TOGETHER

从工具接入，到共同研究

通过评估并完成接入后，开发者将作为干将外部合作成员参与生态共建。共同产出的论文、技术文章及项目贡献记录，将根据实际研究、开发与写作贡献协商署名。
